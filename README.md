# Gravity Simulation instructions and description
This program is a gravity simulation that simulates point masses using Newton's laws of motion. To use the program, one should input their desired starting conditions in 'config.py' or can choose a given preset in the same place. All units are root metric units (e.g., meters, not centimeters or kilometers). This means that the values you input and that are shown are the same things that would happen in the real world given these values! Of course only to an extent, as we are making plenty of assumptions, including that Newtonian gravity applies, there are no other forces acting on the bodies, and all of the mass is concentrated in a single point, among numerous other things. Math and physics equations used in the program are commented in blue if you have the Better Comments extention.

Regardless, I still think it is fun to visualize these orbits and to have the ability to input a few values and have the program create an orbit for you. Enjoy messing around; if you find any bugs I missed or have any ideas on features, email me at nialltheillini@illinois.edu.
