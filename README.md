## Gravity Simulation instructions and description
This program is a gravity simulation that simulates point masses using Newtons laws of motion. To use the program one should input their desired staring condiitons in 'config.py' or should choose a given preset in the same place. All units are root metric units (eg. meters, not centimeters or kilometers). This means that the values you input and that are shown are the same things that would happen in the real world! Of course only to an extent as we are making plenty of assumptions including that only Newtonian gravity applies, there are no other forces acting on the bodies, all of the mass in concentrated in a single point, among numerous others. 

Regardless I think it is still fun to visualize these orbits and the ability to input a few values and have the program create an orbit for you. Enjoy messing around, if you find any bugs I missed or have any ideas on features email me at: nialltheillini@illinois.edu.

# A note about my approach:
This approach to position and velocity being updated once per time step has a trade off: it lowers accuracy compared to integration but results in faster speeds and simplicity. This means that over long run times the program can become inaccurate, but they aren't noticable until multiple minutes have passed. It allows the program to run in real time without other sacrafices. All units are in root metric units.
